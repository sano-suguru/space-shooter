# 新ボス設計仕様書

## 📋 概要

スペースシューターゲームに追加する3種類の新ボス（中級ボス）の詳細設計仕様書です。既存ボスを初級として位置づけ、段階的戦闘フェーズを持つより挑戦的なボス戦を提供します。

## 🎯 設計方針

### 基本コンセプト
- **段階的戦闘フェーズ**: 体力減少に応じて攻撃パターンが変化
- **特化型設計**: 攻撃・防御・機動の3つの異なる戦闘スタイル
- **難易度階層**: 既存ボス（初級）→ 新ボス（中級）の段階的難易度上昇
- **統一感のあるデザイン**: プレイヤーと同じカラーパレットを使用

### 技術制約
- [`GameObject`](../src/entities/GameObject.ts)継承構造を維持
- [`GameConfig`](../src/config/GameConfigFactory.ts)による設定注入対応
- モバイル対応を考慮した操作性
- 既存アーキテクチャとの統合

## 🚀 ボス1: アサルト・クルーザー（攻撃特化型）

### 基本仕様
- **コンセプト**: 重武装戦闘艦による圧倒的火力攻撃
- **登場タイミング**: Wave 10-15
- **体力**: 75
- **移動速度**: 40（既存ボス50より遅い）
- **サイズ**: 180x120（横長の戦艦型）
- **報酬**: 1000ポイント

### 戦闘フェーズ設計

#### フェーズ1: 集中砲火（100%-70%）
- **攻撃パターン**: 3連バースト弾
  - プレイヤー方向への集中射撃
  - 弾丸速度: 250
  - 発射間隔: 800ms
- **移動パターン**: 左右の緩やかな移動
- **特徴**: 高精度だが予測可能な攻撃

#### フェーズ2: 拡散爆撃（70%-30%）
- **攻撃パターン**: 7方向拡散弾 + 爆発弾
  - 爆発弾は着弾後0.5秒で爆発
  - 爆発範囲: 半径30
  - 発射間隔: 600ms
- **移動パターン**: より激しい左右移動
- **特徴**: 範囲攻撃による回避困難化

#### フェーズ3: 絶望の砲撃（30%-0%）
- **攻撃パターン**: レーザービーム + 拡散弾
  - レーザー: 2秒チャージ → 1秒発射
  - 拡散弾発射間隔: 400ms
- **移動パターン**: 画面中央付近で小刻み移動
- **特徴**: 持続ダメージと弾幕の複合攻撃

### 視覚デザイン
- **基本色**: プライマリ（#1a237e）+ エンジン（#ff9800）
- **形状**: 角張った戦艦型、多数の砲塔
- **エフェクト**: 
  - 砲口の発光エフェクト
  - 爆発時の火花パーティクル
  - レーザーチャージ時の集光エフェクト
- **アニメーション**:
  - 砲塔の回転
  - エンジンの脈動
  - ダメージ時の船体振動

## 🛡️ ボス2: シールド・ガーディアン（防御特化型）

### 基本仕様
- **コンセプト**: 多層防御システムによる耐久戦型ボス
- **登場タイミング**: Wave 16-21
- **体力**: 100
- **移動速度**: 30（最も遅い）
- **サイズ**: 160x160（正方形の要塞型）
- **報酬**: 1200ポイント

### 戦闘フェーズ設計

#### フェーズ1: シールド展開（100%-70%）
- **シールドシステム**: 3層エネルギーシールド
  - 各層10ダメージで破壊
  - 10秒毎に1層自動再生
- **攻撃パターン**: 5方向拡散弾
  - 発射間隔: 1200ms
- **移動パターン**: 最小限の位置調整
- **特徴**: 防御重視、長期戦を強要

#### フェーズ2: 反撃モード（70%-30%）
- **シールドシステム**: 2層シールド
  - 破壊時に反撃弾を自動発射
- **攻撃パターン**: 反射弾 + 拡散弾
  - 反射弾は壁で跳ね返る
  - 発射間隔: 1000ms
- **特殊能力**: ダメージ時の衝撃波
- **特徴**: 攻撃的防御への転換

#### フェーズ3: 最後の砦（30%-0%）
- **シールドシステム**: 1層超高耐久シールド
  - 20ダメージで破壊
- **攻撃パターン**: 全方向弾幕
  - 12方向同時発射
  - 発射間隔: 800ms
- **緊急回復**: 体力15以下で+10回復（1回限り）
- **特徴**: 最後の抵抗、全力攻撃

### 視覚デザイン
- **基本色**: セカンダリ（#3f51b5）+ アクセント（#00bcd4）
- **形状**: 六角形ベースの要塞型、多層シールドリング
- **エフェクト**:
  - シールドの波紋エフェクト
  - 回復時の光の柱
  - 衝撃波の円形エフェクト
- **アニメーション**:
  - シールドリングの回転
  - コアの脈動
  - シールド破壊時の破片エフェクト

## ⚡ ボス3: ストーム・インターセプター（機動特化型）

### 基本仕様
- **コンセプト**: 高速戦闘機による予測困難な機動戦
- **登場タイミング**: Wave 22+
- **体力**: 80
- **移動速度**: 80（既存ボスの1.6倍）
- **サイズ**: 120x80（縦長の戦闘機型）
- **報酬**: 1500ポイント

### 戦闘フェーズ設計

#### フェーズ1: 高速機動（100%-70%）
- **攻撃パターン**: 追尾弾
  - 3秒間プレイヤーを追跡
  - 発射間隔: 1500ms
- **移動パターン**: 8の字飛行、急加速・急停止
- **特殊能力**: 無敵ダッシュ（2秒間、5秒毎）
- **特徴**: 高機動による回避重視

#### フェーズ2: 分身攻撃（70%-30%）
- **攻撃パターン**: 分身弾 + 追尾弾
  - 分身弾は3つに分裂
  - 発射間隔: 1200ms
- **移動パターン**: ジグザグ移動 + 瞬間移動
- **特殊能力**: 3秒毎の瞬間移動（画面端から端へ）
- **特徴**: 予測困難な位置変化

#### フェーズ3: 嵐の突撃（30%-0%）
- **攻撃パターン**: 突撃攻撃 + 連続追尾弾
  - プレイヤーに向かって高速突進
  - 発射間隔: 800ms
- **移動パターン**: 突撃→後退→突撃のループ
- **特殊能力**: 突撃時無敵、突撃後短時間停止
- **特徴**: 高リスク・高リターンの攻撃チャンス

### 視覚デザイン
- **基本色**: アクセント（#00bcd4）+ エンジン（#ff9800）
- **形状**: 流線型戦闘機、可変翼システム
- **エフェクト**:
  - 高速移動時の軌跡エフェクト
  - 瞬間移動のワープエフェクト
  - 突撃時のオーラエフェクト
- **アニメーション**:
  - 翼の角度変化
  - エンジンの強烈な発光
  - 残像エフェクト

## 🔧 技術実装仕様

### 新しいクラス構造

```typescript
// 高度なボス基底クラス
abstract class AdvancedBoss extends GameObject {
  protected currentPhase: number = 1;
  protected phaseThresholds: number[] = [0.7, 0.3];
  protected phaseAttackPatterns: AttackPattern[];
  protected phaseTransitionEffects: Effect[];
  
  abstract updatePhase(): void;
  abstract executePhaseAttack(): void;
  abstract onPhaseTransition(newPhase: number): void;
}

// 攻撃パターンインターface
interface AttackPattern {
  type: 'burst' | 'spread' | 'homing' | 'laser' | 'explosive';
  bulletCount: number;
  fireRate: number;
  bulletSpeed: number;
  specialProperties?: SpecialProperty[];
}

// 特殊効果インターface
interface SpecialProperty {
  type: 'explosive' | 'homing' | 'bouncing' | 'splitting';
  parameters: Record<string, number>;
}
```

### 新しい弾丸タイプ

1. **爆発弾（ExplosiveBullet）**
   - 着弾時に範囲ダメージ
   - 爆発エフェクト付き

2. **追尾弾（HomingBullet）**
   - プレイヤーを一定時間追跡
   - 追跡軌跡の可視化

3. **反射弾（BouncingBullet）**
   - 壁で跳ね返る特性
   - 最大反射回数制限

4. **分身弾（SplittingBullet）**
   - 一定距離で複数に分裂
   - 分裂時のエフェクト

## 📊 バランス調整

### 難易度階層
- **Wave 1-9**: 既存ボス（初級）- 体力50、基本攻撃
- **Wave 10-15**: アサルト・クルーザー - 体力75、高火力
- **Wave 16-21**: シールド・ガーディアン - 体力100、高防御
- **Wave 22+**: ストーム・インターセプター - 体力80、高機動

### 報酬システム
- **既存ボス**: 500ポイント
- **アサルト・クルーザー**: 1000ポイント
- **シールド・ガーディアン**: 1200ポイント
- **ストーム・インターセプター**: 1500ポイント

### プレイヤー成長との連動
- 各ボスはプレイヤーの成長段階に応じた挑戦を提供
- 段階的な難易度上昇により学習曲線を最適化
- 各特化型により異なる戦略の習得を促進

## 🎮 ユーザーエクスペリエンス

### 戦闘の多様性
1. **アサルト・クルーザー**: 火力への対処、回避スキルの向上
2. **シールド・ガーディアン**: 持久戦への適応、戦略的思考
3. **ストーム・インターセプター**: 反応速度、予測能力の向上

### 学習要素
- 各フェーズの攻撃パターン学習
- フェーズ移行タイミングの把握
- 各ボスタイプに応じた戦略の開発

### リプレイ価値
- 異なる戦略での攻略
- 最適化されたクリア時間への挑戦
- 各ボスの完全攻略パターンの習得

## 🔄 システム統合

### 既存システムとの連携
- **ウェーブシステム**: 段階的なボス登場スケジュール
- **スコアシステム**: 難易度に応じた報酬調整
- **プログレッションシステム**: ボス撃破による成長要素

### 拡張性

- 特殊イベントボス（複数同時出現等）
